Overview

Infinity Browser is a desktop web browser built as a Python application. It uses QtWebEngine, which embeds Chromium/Blink for modern website rendering, JavaScript, WebAssembly, native PDF viewing, and site video fullscreen.

DeveloperStrangeInfinity
Core stackPython 3.10+, PyQt6, PyQt6-WebEngine, QtWebEngine
Primary platformsLinux source install and Windows packaged installer workflow
Data modelBookmarks, history, notes, downloads, settings, and vault files live locally.

Key Features

Infinity Browser combines essential browsing tools with powerful productivity features, all running locally on your machine.

YouTube Downloader

Built-in video and audio extraction with quality selection, subtitle support, and metadata handling.

Smart Bookmarks

One-click bookmark toggle, searchable bookmark manager, and persistent local storage.

Complete History

Local history with search, latest-first browsing, and full user control.

Download Manager

Ask or auto-save modes, live progress tracking, and organized download history.

Notes Panel

Persistent local notes with search, rename, and autosave—no cloud sync required.

QR Generator

Generate QR codes for the current page, websites, or custom text.

Multiple Search Engines

Google, DuckDuckGo, Bing, Ecosia, and Brave Search.

Tab Management

Full tabbed browsing with reload, new tab, fullscreen, and app-level shortcuts.

YouTube Downloader

Infinity includes a full YouTube downloader dialog powered by yt-dlp. It can be opened from the app menu. If the current page is a supported YouTube URL, the dialog starts with that URL and can immediately fetch video info.

Supported URLs

youtube.com/watch, youtube.com/shorts, and youtu.be.

Modes

Video plus audio, or audio-only extraction.

Quality

Best available or caps at 2160p, 1440p, 1080p, 720p, 480p, or 360p.

Extras

Optional subtitles, auto subtitles, thumbnails, and exact format selection from metadata.

Safety & Privacy First

Infinity Browser prioritizes your privacy and security by storing all data locally on your machine. There is no telemetry collection, no cloud syncing, and no account system. You have complete control over your browsing history, bookmarks, downloads, and personal notes. The app includes built-in security controls for ad blocking, Do Not Track, pop-up blocking, JavaScript management, HTTPS-Only mode, Safe Browsing, and the ability to clear all browsing data at any time.

Architecture

The app starts in main.py, registers the infinity:// scheme, initializes Qt, loads global styling, and opens BrowserWindow. The main window wires together the tab manager, navigation bar, download manager, ad blocker, settings, history, bookmarks, password vault, notes, QR generator, and YouTube downloader.

browser_window.py

Main window, menu, shortcuts, panels, fullscreen, and app orchestration.

tab_manager.py

QtWebEngine profile, tabs, custom scheme handler, page loading, and media fallback.

youtube_downloader.py

yt-dlp process integration, metadata parsing, progress updates, and history registration.

download_manager.py

Browser download requests, save modes, active progress UI, and persisted download history.

settings_dialog.py

General, Appearance, Privacy, Security, and Downloads settings UI.

scheme_handler.py

Serves internal infinity://newtab content from new_tab.html.

Cross-Platform Support

Infinity Browser is designed to work seamlessly on both Windows and Linux, giving you a consistent browsing experience across platforms. Whether you're on Windows 10/11 or modern Linux distributions, you can download and run Infinity Browser with the same features and performance.

Windows

Download the pre-built installer InfinityBrowserSetup-1.0.0-x64.exe. The installer handles all dependencies, creates desktop shortcuts, and preserves your data during updates.

Linux

Download pre-built packages for your distribution: .deb for Debian/Ubuntu and .rpm for Fedora/RHEL systems. Full support for GNOME and other desktop environments.

Local Data Storage

All your bookmarks, history, notes, downloads, settings, and passwords are stored locally in your user directory. Your data stays on your machine.

Updates & Upgrades

Update to new versions while keeping your existing data intact. Reinstalls preserve all your browsing history, bookmarks, and settings.
