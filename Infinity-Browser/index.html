A desktop browser with creator-friendly tools built in.

Infinity is more than a web view. It brings browsing, media capture, local productivity panels, and privacy controls into one native desktop app.

YT

YouTube downloader

Fetch video metadata, pick video or audio-only downloads, cap quality, select exact formats, write subtitles, save thumbnails, and track completed files.

DL

Download manager

Choose ask or auto save modes, watch live speed and progress, open files or folders, redownload from history, and clear download records.

PV

Local-first privacy

No telemetry, no external account system, local JSON persistence, ad blocking, Do Not Track, pop-up blocking, HTTPS-Only, and Safe Browsing controls.

PW

Password vault

Credentials stay on your machine with local encryption, nonces, HMAC integrity checks, and owner-only key file permissions where supported.

QR

QR generator

Create QR codes from the current page, websites, or text without leaving the browser workflow.

UX

Everyday navigation

Tabbed browsing, smart address/search input, bookmarks, history search, notes, PDF export, local file opening, configurable search engines, and app-wide shortcuts.

Made for saving YouTube media cleanly.

The downloader is not a link bolted onto the page. It is part of the desktop app and connects into download history.

Paste a URL. Pick your format. Keep the result.

Infinity detects YouTube watch, Shorts, and youtu.be URLs. From there, it can fetch metadata, show the title, channel, and duration, then download through `yt-dlp` using your chosen output folder.
